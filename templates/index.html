⚡ Quick Creator API Integration

Send single comments or batches via HTTP POST requests: 

# Single Comment Moderation
curl -X POST http://localhost:5000/v1/moderate \
  -H "Content-Type: application/json" \
  -d '{"comment": "R-word"}'

# Batch Comment Moderation
curl -X POST http://localhost:5000/v1/moderate/batch \
  -H "Content-Type: application/json" \
  -d '{"comments": ["R-word", "mar dunga", "Awesome video!"]}'
